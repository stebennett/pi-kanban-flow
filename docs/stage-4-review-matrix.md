# Stage 4 durable-effect and crash review matrix

**Status:** Work unit 0 review matrix

This matrix is the review index for `docs/spec-one-card-lifecycle.md`. Each row names the single authority, the durable effect, the crash/failure window, the required recovery rule, and the focused test that must land with the implementation. A row is not closed by a model claim, an open PR, a local branch, or a mock-only assertion. Tests that exercise GitHub use a fake adapter plus real Git unless the row explicitly requires an opt-in provider/UI spike.
